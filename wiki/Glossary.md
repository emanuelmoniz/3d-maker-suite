# Glossary

Words used in the app and in this guide, in alphabetical order.

| Word | Meaning |
|---|---|
| **Accessory** | A part you fit to a printer, such as an AMS. It can be installed on a printer and has its own maintenance |
| **Admin** | The built-in role that can do everything. It can't be changed or deleted |
| **Archive** | Hide an item from lists and pickers and keep its history. See [Archive and delete](Archive-and-Delete.md) |
| **Auto** | A sync mode that runs by itself on a frequency. See [Sources and sync](Sources-and-Sync.md#auto-and-manual-sync) |
| **Backup** | A copy of the app's data that you can restore. See [Backups and restore](Backups-and-Restore.md) |
| **Bulk action** | Archive, restore or delete many rows of a list at once |
| **Catalog** | The brands, printer models, filament brands and filament materials your printers, spools and prints are described with |
| **Connector** | A small program on a computer that pairs it with the hub. See [Connector setup](Connector-Setup.md) |
| **Data folder** | The folder that holds the database, backups and the key for saved logins. See [Configuration](Configuration.md#where-your-data-is-kept) |
| **Data type** | A kind of thing a source can bring in: printers, prints, spools, catalog, presets or projects |
| **Docker** | A way to run the app in a container, often on a NAS or server. See [Docker](Docker.md) |
| **Filament** | The material you print with. In the app it is made of brands, materials, presets and spools |
| **Hub** | The app run as the central server that computers pair with. See [Hub setup](Hub-Setup.md) |
| **Integration** | A connection to an outside service or a printer, set up in **Settings → Integrations** |
| **Machine** | A computer paired with the hub through the connector. It is listed in **Hub management** |
| **Manage** | The highest right of a module. It lets you set the module up and do bulk actions |
| **Manual** | A sync mode that runs only when you click **Sync now** |
| **Migration** | A change to the database made when a new version starts. It only goes forward |
| **Module** | A part of the app with its own right, such as Printers, Filament or Projects |
| **Pairing** | Linking a computer to the hub with a one-time code |
| **Pick** | A hub project folder that a computer receives |
| **Plate** | One print job inside a project, with its own time and filament |
| **Preset** | A set of slicer settings for a printer, a process (the print settings) or a filament. Presets come only from a slicer |
| **Print** | One recorded print job, with its filament and cost |
| **Project** | A model or job with its files, plates, prints and costs |
| **Public address** | The address the app is reached at from outside, used in the links of alerts. See [Server and remote access](Server-and-Remote-Access.md) |
| **Quote** | An offer to a client with an estimated price, which can become an order |
| **Restore** | Bring an archived item back, or replace the app's data with a backup |
| **Reverse proxy** | A server in front of the app that serves HTTPS. See [Server and remote access](Server-and-Remote-Access.md) |
| **Review and import** | The screen where you decide on rows a sync found. See [Sources and sync](Sources-and-Sync.md#review-and-import) |
| **Role** | A named set of rights given to users. Built in: Admin, Editor and Viewer |
| **Setup token** | A one-time code, printed in the console, that allows creating the first admin from another device. See [First run](First-Run.md) |
| **Shared folder** | A folder on a paired computer that the hub reads projects from |
| **Slicer** | A program that prepares a model for printing, such as Bambu Studio or OrcaSlicer |
| **Source** | Anything that feeds the app with data. See [Sources and sync](Sources-and-Sync.md) |
| **Spool** | One roll of filament, with its weight, price and opened date |
| **Sync** | Reading data from a source into the app |
| **Track usage** | Subtract the filament of a print from your spools' weights |
| **User accounts** | The switch in **Settings → General** that makes everyone sign in |
| **Write** | The right to add and edit things in a module, below **Manage** |
